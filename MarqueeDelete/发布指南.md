# 发布到 Paradox Mods 操作指南

本模组是 **Code Mod**（含 C# 程序集 + UI 模块），发布走官方的 `ModPublisher.exe`。
不需要订阅费，但需要 **Paradox 账号**，且第一次发布前必须**在游戏内登录过一次**。

---

## 0. 前置条件（缺一不可）

| 项目 | 状态 | 说明 |
| --- | --- | --- |
| Paradox 账号 | 需要 | <https://mods.paradoxplaza.com/> 免费注册 |
| 游戏内登录 | **必须做过一次** | 启动游戏 → 主菜单右上角登录 PDX 账号。`ModPublisher` 会自动复用这份登录态（本机 `.pdxsdk/` 里已存在 `LoggedIn=True`） |
| Modding Toolchain | 已安装 | 本机 `D:\steam\...\.ModdingToolchain\ModPublisher\ModPublisher.exe` 已就位 |
| .NET 6+ 运行时 | 已安装 | 本机有 6.0.8 / 6.0.36 / 8.0.33，满足要求 |

> 登录态存放于
> `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\.pdxsdk\<SteamID>\database.json`。
> 若发布时报登录失败，回游戏重新登录一次即可，**不要**手动删这个文件。

## 1. 完善发布信息（`Properties/PublishConfiguration.xml`）

这是唯一决定"模组页面上显示什么"的文件。已经为本项目建好，逐项确认：

```xml
<Publish>
    <ModId Value="" />                     <!-- 首次发布留空，发布后回填 -->
    <DisplayName Value="Marquee Delete" />
    <ShortDescription Value="Drag a box to bulk-delete ..." />
    <LongDescription> ... </LongDescription>
    <Thumbnail Value="Properties/Thumbnail.png" />
    <Tag Value="Code Mod" />               <!-- 必填，见下方说明 -->
    <ModVersion Value="2.1.0" />
    <GameVersion Value="1.6.4f1*" />
    <ChangeLog Value="Initial public release." />
</Publish>
```

### 发布器会强制校验的 7 个字段

`ModPublisher` 在字段为空时会直接失败。缺任何一个都会打印类似
`DisplayName must be set in configuration`：

| 字段 | 校验报错文案 |
| --- | --- |
| `DisplayName` | `DisplayName must be set in configuration` |
| `ShortDescription` | `ShortDescription must be set in configuration` |
| `LongDescription` | `LongDescription must be set in configuration` |
| `Thumbnail` | `Thumbnail must be set in configuration` |
| `ModVersion` | `ModVersion must be set in configuration` |
| `GameVersion` | `GameVersion must be set in configuration` |
| `Tag`（至少 1 个） | `at least one Tag must be set in configuration` |

### 关于 Tag

代码模组用 `Code Mod`。可选类型还有 `Asset` / `Map` / `Save Game` / `Scenario` 等。
**标签影响玩家在 Paradox Mods 的筛选，选错会导致模组被归类到"资产"分类下。**

### 关于缩略图尺寸（重要）

Paradox Mods 的模组卡片是**正方形**。参考本机已下载的 94 个 CS2 模组缩略图：
90 个是 1:1（600×600、1024×1024、1080×1080…），仅 8 个是 1920×1080。

因此本项目用 **1024×1024**。生成脚本：

```powershell
py -3 Properties\make-thumbnail.py
# → Properties\Thumbnail.png  1024x1024
```

想要真实游戏截图，替换同一路径的 `Thumbnail.png` 即可（建议先裁成 1:1，否则会被裁切）。

### 长描述的书写规则

`LongDescription` 和 `ChangeLog` 支持**极简 Markdown**：标题、无序列表、粗体。

⚠️ 官方明确警告：`<LongDescription>` 内的**多行文本每行行首不能有空格/缩进**，
否则会被当作代码块或被文本编辑器改写。本项目已按此书写（行首顶格）。

## 2. 三个发布模式

官方提供三种操作，对应 VS/Rider 的三个发布配置：

| 模式 | 用途 | 需要 `ModId` |
| --- | --- | --- |
| `Publish` | **首次**上传，创建新模组 | ❌ 不需要 |
| `NewVersion` | 上传**新版本**（新文件 + 新版本号 + 更新日志） | ✅ 必须 |
| `Update` | 只改**页面信息**（描述、缩略图、标签），不传新文件 | ✅ 必须 |

首次发布后，控制台会输出 `Mod published with Id=<数字>`。
**把这个数字回填到 `PublishConfiguration.xml` 的 `ModId`**，后续两个模式才能用。

## 3. 执行发布

项目根目录已提供封装脚本 `publish.ps1`，它会自动完成"整理内容目录 → 校验 → 调用发布器"。

### 首次发布

```powershell
cd "C:\Users\aaa20\Desktop\新建文件夹\MarqueeDelete"

# 1) 先编译（确保 dist\ 是最新的）
pwsh -File .\build.ps1
cd ui; npm run build; cd ..

# 2) 预演：只整理内容目录并打印命令，不上传
pwsh -File .\publish.ps1 -Mode Publish -DryRun

# 3) 正式发布
pwsh -File .\publish.ps1 -Mode Publish
```

看到下面这行就成功了：

```
Mod published with Id=123456
Mod publishing process finished successfully
```

**立刻**把 `123456` 回填：

```xml
<ModId Value="123456" />
```

### 发布新版本

```powershell
# 1) 改版本号（两处必须一致）
#    Properties\PublishConfiguration.xml → <ModVersion Value="2.2.0" />
#    mod.json                            → "version": "2.2.0"
# 2) 写更新日志
#    Properties\PublishConfiguration.xml → <ChangeLog> ... </ChangeLog>
# 3) 重新编译并发布
pwsh -File .\build.ps1
cd ui; npm run build; cd ..
pwsh -File .\publish.ps1 -Mode NewVersion
```

### 只改页面信息

改了描述、缩略图、标签，但代码没变时：

```powershell
pwsh -File .\publish.ps1 -Mode Update
```

### 直接调用发布器（不用封装脚本）

```powershell
& "D:\steam\steamapps\common\Cities Skylines II\Cities2_Data\Content\Game\.ModdingToolchain\ModPublisher\ModPublisher.exe" `
    Publish ".\Properties\PublishConfiguration.xml" `
    -c ".\publish\MarqueeDelete" -v
```

可用参数：`-e <邮箱>` `-p <密码>` `-l <登录文件>` `--noAutoLogin` `-c <内容目录>` `-v`

## 4. 内容目录里必须有什么

`-c` 指向的目录会被打包上传。它的结构必须和游戏加载本地模组的布局**完全一致**
（即 `Mod.targets` 里 `DeployDir` 的布局：文件平铺在模组文件夹根下）。

`publish.ps1` 会自动整理成下面这样：

```
MarqueeDelete/
├── MarqueeDelete.dll              70,144   必需 — C# 逻辑
├── MarqueeDelete.mjs              15,182   必需 — UI 模块
├── MarqueeDelete.css               4,238   必需 — UI 样式
├── MarqueeDelete.mjs.LICENSE.txt     249   React 许可声明
├── MarqueeDelete.pdb              17,316   可选 — 出错时的堆栈可读
├── mod.json                          662   必需 — id / isCodeMod / dependencies
└── images/
    └── marquee-delete-icon.svg       888   UI 图标
```

> **不需要** `_win_x86_64.dll` / `.so` / `.bundle`：那是 Burst 编译器的产物。
> 本项目没用 `[BurstCompile]`（`grep` 已确认），所以没有也不需要这些文件。

## 5. 发布后

1. 打开 <https://mods.paradoxplaza.com/> → 头像 → **My mods**
2. 检查显示名称、缩略图、描述、标签是否正确
3. Paradox 侧通常需要**审核**才会公开（新账号 / 首次发布尤其如此）
4. 通过后玩家即可在游戏内 **Paradox Mods** 标签页订阅

### 更新节奏建议

- 游戏小版本更新（如 `1.6.4f1` → `1.6.5f1`）后，**先本地跑一遍**再 `NewVersion`
- `GameVersion` 使用已验证的游戏短版本加尾部通配符（如 `1.6.4f1*`）。平台只接受 1 至 12 个字符，游戏内商店用该字段匹配完整构建字符串。运行时继续由 `Mod.cs` 校验实际的游戏程序集
- 破坏性改动（存档不兼容、需要新依赖）务必写进 `ChangeLog`

## 6. 常见问题排查

| 现象 | 原因 / 解决 |
| --- | --- |
| `DisplayName must be set in configuration` 等 | 上述 7 个必填字段有空值，补齐即可 |
| `at least one Tag must be set in configuration` | 忘了 `<Tag Value="Code Mod" />` |
| `Thumbnail must be set in configuration` | `Properties\Thumbnail.png` 不存在，跑 `py -3 Properties\make-thumbnail.py` |
| `Not supported in release mode` | 用了 `--sandbox`（仅调试版可用）。正式发布去掉该参数 |
| 登录失败 / `LoginRequired` | 回游戏主菜单重新登录 PDX 账号，再发布 |
| `Mode 'NewVersion' requires <ModId .../>` | 首次发布还没回填 `ModId` |
| 上传后模组页面空白无图 | 缩略图不是 1:1，被平台裁掉了；换成正方形 |
| 玩家订阅后无效 | 检查 `mod.json` 的 `id` 与 `isCodeMod`；确认 dll/mjs/css 都在内容目录根下 |
| 中文描述变成乱码 | `PublishConfiguration.xml` 必须存为 **UTF-8**（无 BOM） |

## 7. 上传前自检清单

```powershell
# 1) 编译与测试全绿
pwsh -File .\build.ps1
cd ui; npx tsc --noEmit; npm run build; cd ..
pwsh -File .\tests\run_tests.ps1          # 期望 passed=160, failed=0
pwsh -File .\tests\verify_cecil.ps1       # 期望 UnresolvedCount=0

# 2) 版本号两处一致
Select-String -Path mod.json,ui\mod.json,Properties\PublishConfiguration.xml -Pattern '2\.\d+\.\d+'

# 3) 内容目录完整
pwsh -File .\publish.ps1 -Mode Publish -DryRun

# 4) 语法预检（字段校验会全部打印出来）
& "D:\steam\steamapps\common\Cities Skylines II\Cities2_Data\Content\Game\.ModdingToolchain\ModPublisher\ModPublisher.exe" `
    Publish ".\Properties\PublishConfiguration.xml" -c ".\publish\MarqueeDelete" -v
```

第 4 步在正式上传前会把 `DisplayName / ShortDescription / LongDescription /
Thumbnail / ModVersion / GameVersion / Tag` 全部打印出来，**人工核对一遍**再确认上传。
