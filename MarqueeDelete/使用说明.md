# 框选批量删除（Marquee Delete）使用说明

## 适用版本
- 目标游戏版本：`Cities: Skylines II 1.6.4f1`（内置 `Game.dll` MVID 校验，不符时自动安全停用）。
- 原先存在的若干致命问题已全部修复：
  1. 修复了错误跳过带 `SubObject`/`SubNet`/`SubArea` 缓冲区父实体（几乎所有建筑）的问题，仅跳过真正从属于父级的非移动子实体，并由级联逻辑完整联动删除升级模块、子建筑/摆件与安全附属网络。
  2. 修复了原版强行用平地 `y = 0` 求交导致山地/坡地鼠标框选飘移数公里的问题，现通过 `ToolBaseSystem` + `ToolRaycastSystem`（`TypeMask.Terrain | TypeMask.Water`）实时拾取真实地形与水面高度。
  3. 修复了未完成 `NativeQuadTree` 依赖 `deps.Complete()` 导致的竞态漏选问题。
  4. 使用 `OverlayRenderSystem` 绘制地形贴合的框选线、建筑分区地块框与远景分组。
  5. 新增基于 `ModSetting` 的可重绑快捷键（默认开启工具 `Ctrl+Shift+X`，确认删除 `Enter`）、中文/英文双语选项界面以及游戏内悬浮过滤面板。

## 使用方法
1. **激活工具**：点击原版推土机面板中的「框选批量删除」按钮，或按 `Ctrl + Shift + X`（可在游戏 设置 -> 模组 -> 框选批量删除 中自由重绑）。
2. **拖框选择**：
   - 在地图上**按住鼠标左键拖动**即可绘制贴合地形、且随镜头视角朝向旋转的红色选框（可在设置/面板中关闭“随视角旋转”改回正南正北）。
   - 拖动时实时预览目标数量。建筑用分区颜色显示地块框，远景大选区用同色分组标记。道路和树木保留原生轮廓。松开左键后锁定结果。
3. **确认 / 重选 / 取消**：
   - **确认删除**：按 `Enter` 键，或点击悬浮面板上的红色「确认删除」按钮；若在设置或面板中取消勾选“删除前确认”，低于安全阈值（默认 50）的小批框选会在松开左键时直接删除。
   - **直接重画**：在已选中等待确认的状态下，直接按住左键拖动大于 0.5m 的新框即可直接重选，无需额外先按清空；误点不会丢失已选内容。
   - **右键 / 退出**：拖动中按右键取消本次拖动；已锁定结果时按右键清空选区（仍留在工具内）；空闲时按右键或点击「退出」回到默认工具。

## 悬浮面板与过滤类别
- **建筑 / 树木 / 摆件 / 贴花**：默认开启。
- **车辆市民**：默认关闭；开启后可用于快速框选清理拥堵车辆与行人，且自动识别多节列车/有轨电车整列（`LayoutElement` / `Controller`）一并安全清除。
- **地表（Surface / Space / Lot）**：默认关闭；仅针对可编辑涂装表面与地块，地图区块（`MapTile`）与行政区（`District`）永远强制保护。
- **道路管网（慎用）**：默认关闭；选中道路时会自动检查路口连接边，共享道路交叉节点不会在仍有其他相连道路时被误删。
- **安全保护**：默认保护地图边缘外部连接（高速公路/铁路/水电对外接口），可选保护独特建筑。
- **可选资产分步撤回**：点击「撤回上步」或按 `Ctrl+Z` 可从六类静态资产中自由勾选要恢复的目标——建筑（连同其扩建、附属院落与内部通道）、道路管网、地表、树木、摆件、贴花；每个开关显示当前快照中该类记录数量。重建请求按帧耗时预算分批提交（带父实体查询缓存），最多保留 5 份快照、每份快照最多 8,000 条记录；达上限、未能捕获或跳过对象时会明确提示。进度表示已提交请求，不保证游戏已完成重建；只恢复几何与部分属性，不恢复住户、经济与完整模拟状态，车辆市民不支持撤回。
- **暂停与回滚建议**：「暂停」保留剩余请求，再点撤回可继续；撤回进行中或暂停时禁止新的框选删除。需要确定的回滚，请直接读取较早的存档。

在「选项 → 框选批量删除 → 常规设置 → 模组语言」可选择汉语、英语或跟随游戏，默认跟随游戏。
